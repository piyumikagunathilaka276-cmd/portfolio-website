# Portfolio Website

This is my personal portfolio website built using React, Vite, and Tailwind CSS.  
It showcases my projects, skills, education, and contact details as an undergraduate software engineering student looking for internship opportunities.

## Features

- Responsive design for desktop and mobile
- Clean and modern UI
- Project showcase section
- Skills and education sections
- Contact section with email, GitHub, and LinkedIn links

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- JavaScript
- Git & GitHub
